# MySCUT v0.8.3

## 主要更新

- 降低课表页面 header 高度
- 加入 “保留上次查看的周数” 全局开关
- 更新 “启用本地手册” 设置说明
- 现在添加/修改课程时可设置周数间隔
- 添加课程的教师默认文本改为 “待定教师”
- 现在删除某课程安排时，不会把同名的所有课程全部删除，而是只删除某个课程安排
- 修复了添加同名课程的新安排时名称显示错误的问题
- 现在消息弹出完毕后不会重置页面状态（突发跳转等）
- 添加 “学期已结束” 和 “学期未开始” 标识
- 现在不能滑动到最后一周往后的周数
- 现在设置的学期初始时间是各课表独立的
- 添加 “返回当前周” 的滑动动画
- 为 qmui 添加液态玻璃模态窗口和滚轮选择器，并应用于 “选择周次” 界面上
