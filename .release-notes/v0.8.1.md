# MySCUT v0.8.1

## 主要更新

- 添加 2x4 安卓小组件，显示今日剩余课程（实验性）
- 修复了初始日期不是周一时，星期与真实日期不一致的问题
- 现在若初始日期不是周一，在课表页面会以初始日期对应的星期对齐
- 更新初始日期逻辑，现在会自动寻找 9-1 或 3-1 最近的周一作为默认初始日期
- 修复滑动后，按钮 “回到当前周” 需双击的问题
- 给按钮 “回到当前周” 添加涟漪动画
- 给本周当天加入高亮效果
- 修复导入 HTML 导入时，若教师名字姓周，解析错误 `maxWeek` 的问题
- 移除当天日期标题，并加入选择周数下拉菜单
- 添加课程增删改查功能，初步更新 UI
- 现在下拉时表头不会滚动
- 现在横向滚动时，下拉的位置状态会保留
- 修复 Android 上导入启梦文件 QMS 时不能选择 `*.qms` 文件的问题
- 引入自研 qmui 设计系统，底部导航呈现 iOS 26 液态玻璃风格（圆角玻璃胶囊 + 滑动切换动画）
