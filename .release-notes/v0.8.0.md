# MySCUT v0.8.0

## 升级前必读

- v0.8.0 起更换正式签名密钥，**v0.7.3 及更早版本无法在应用内直接升级**，直接更新会提示安装失败
- 迁移步骤：旧版「课表设置 → 导出课表」备份 → 卸载旧版 → 从 [Releases 页](https://github.com/Kozmosa/MySCUT/releases)安装 v0.8.0 → 重新导入课表
- 本版本之后恢复正常的原地升级，后续无需再卸载

## 主要更新

- 发版体系迁移至 GitHub Actions CI，发版不再依赖维护者的本地环境
- 新增 Nightly 通道：独立包名 `com.manual.univ.nightly`（应用名 MySCUT Nightly），可与正式版并排安装、数据相互独立，供尝鲜与测试，见 [Nightly Releases](https://github.com/Kozmosa/MySCUT/releases)
- 更新检查新增最低可升级版本（minVersion）机制，低于最低版本的客户端将收到迁移指引
- 本版本无课表功能层面的变化，后续功能更新以正常节奏发布
