# MySCUT v0.7.3

## 主要更新

- 尝试修复教务导入输入法挤占页面的问题
- 修复教务导入图表链接无法进入
- 修复原生平台上压缩 QMS 的剪切板导入/导出
- 更新默认初始日期逻辑
- 添加导入课程表后修改初始日期的提示
- 修改默认时间表为大学城/国际校区
- 修复原生设备上的课程表导出
- 让导出的课表名称与修改的名称同步
- 现在手册页面在切换 tab 时默认会保留，可打开“进入手册时重新加载”关闭该行为
- 现在原生的返回会关闭打开的模态窗口，并且返回时不再回到上次的页面，而是按固定上级页面返回
- 现在在课表页面需要返回两次才能退出应用，并且返回一次时有“再按一次返回键退出应用”的提示
