# Issue tracker

MySCUT 的工作项和 PRD 使用当前仓库的 GitHub Issues，通过 `gh` CLI 读取和维护。

- 创建、查看、编辑、标记和关闭 issue 时使用当前 Git remote 推断仓库。
- “发布到 issue tracker”表示创建 GitHub issue。
- issue 正文应包含背景、范围、非目标、验收标准、验证方式和依赖，不依赖未记录的口头上下文。
- 不在 issue 中粘贴真实课表、Cookie、Token、API Key 或其他敏感数据；安全问题按 [SECURITY.md](../../SECURITY.md) 私下报告。
