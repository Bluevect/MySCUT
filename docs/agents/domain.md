# Domain docs

MySCUT 是单一领域语境仓库。

- 开始产品或代码探索前先读根目录 [CONTEXT.md](../../CONTEXT.md)，在 issue、测试和实现中使用其中的统一词汇。
- 再阅读与当前工作相关的 [ADR](../adr/)；若方案与已有 ADR 冲突，必须明确指出。
- `CONTEXT.md` 只维护产品领域词汇，不记录实现步骤、临时计划或技术细节。
- 只有长期有效、存在真实取舍且未来读者需要理解原因的决策才进入 `docs/adr/`；普通实现由 commit 和 Pull Request 记录。
- 产品目标和长期工程边界仍以 [PROJECT_BASIS.md](../../PROJECT_BASIS.md) 为准。
