# Triage labels

以下五个标签只表达 issue 当前状态；`bug`、`enhancement`、`documentation` 等现有标签继续表达工作类型。

| 状态 | GitHub label | 含义 |
| --- | --- | --- |
| 待评估 | `needs-triage` | 维护者需要判断范围和优先级 |
| 待补信息 | `needs-info` | 等待报告者或维护者补充必要信息 |
| Agent 可领取 | `ready-for-agent` | 需求和验收标准完整，无需额外口头上下文 |
| 需人工 | `ready-for-human` | 需要真实设备、人工判断或产品决策 |
| 不处理 | `wontfix` | 已决定不采取行动 |
