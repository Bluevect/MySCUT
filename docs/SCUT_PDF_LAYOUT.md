# 华工教务 PDF 固定布局合约

首个可支持的 PDF 合约标识为 `scut-student-timetable-v1`。它只描述华南理工大学教务系统导出的、带可选择文本层的学生个人课表，不是通用 PDF 表格识别器。

## 页面与网格

- 文件必须只有 1 页；页面旋转角为 `0`。
- 页面使用横向 A4 坐标，PDF.js 在缩放比例 `1` 下的页面尺寸为 `842 × 595` 点，宽高各允许 `18` 点误差。
- 固定标题为“华南理工大学学生个人课表”。
- 页眉必须提供学年（`YYYY-YYYY`）、学期、学号、校区和课表编号。
- 课表网格左上角为 `(28, 132)`，节次列宽 `58` 点，星期列宽 `104` 点，表头高 `25` 点。
- 网格有星期一至星期日 7 列，以及第 1 至第 12 节 12 行；每节行高 `34` 点。
- 星期列和节次行不仅要有对应文字，还必须出现在上述固定列、行范围内。仅包含相似文字但坐标不匹配的 PDF 会被拒绝。

这些数字是 `src/core/schedule/importScutPdf.ts` 中 `SCUT_PDF_FIXED_LAYOUT` 的可执行定义。调整它们意味着支持新的布局版本，不能静默扩大当前版本的识别范围。

## 课程单元格

每个课程单元格从“课程”字段开始，并依次包含以下 6 行：

1. 课程名称；
2. 周次；
3. 节次；
4. 教师；
5. 地点；
6. 学分。

课程名称、教师、地点和学分不能为空。节次必须落在 1 至 12 节之间，课程文本的纵向位置必须与起始节次所在行一致。一个课程可以跨越多个连续节次。

周次支持以下固定写法，中文全角括号和逗号会先被规范化：

- 连续周：`1-16周`；
- 单双周：`1-15周(单)`、`2-16周(双)`；
- 明确步长：`2-14/2`；
- 多个周段：`1-4周,9-12周`。

合约输出会保留原始周次表达式，并生成 `startWeek`、`endWeek`、`weekStep`。这一阶段不创建或保存 `ScheduleData`。

## 公开合成证据

- `tests/fixtures/public/scutSchedule.synthetic.pdf` 是受支持样例。
- `tests/fixtures/public/scutSchedule.unsupported.synthetic.pdf` 是格式拒绝样例。
- 两个文件都由 `npm run build:scut-pdf-fixtures` 调用 `scripts/generateScutPdfFixtures.mjs` 重建，不依赖真实学生 PDF 或 PDF 生成库。
- 公开样例的课程、教师、地点、学生和课表编号全部使用 `TEST-*` 数据。
- 合成 PDF 保留中文固定标题和星期标签，同时使用同坐标的 ASCII 字段别名，避免测试依赖开发机中文字体的字符映射；生产合约仍接受教务 PDF 的中文字段名。

## 明确拒绝范围

以下输入不属于 `scut-student-timetable-v1`，必须返回可行动的格式错误，且不得产生部分课表：

- 扫描件、截图、图片 PDF 或其他没有可选择文本层的文件；
- OCR 结果；
- 其他学校的课表；
- 任意表格 PDF、手工编辑后只保留相似文字的 PDF；
- 多页课表、旋转页面、未知尺寸或未知坐标布局；
- 缺少固定页眉、星期列、节次行或任一课程必填字段的文件；
- 新版或未知的华工课表导出布局。

发现新的华工布局时，应新增独立合约版本、合成 fixture 和回归测试，不应放宽本版本使其猜测未知结构。
